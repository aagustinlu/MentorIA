# MentorIA

Transforma cualquier tema en un curso estructurado al instante. Escribes lo que quieres aprender mediante un prompt y MentorIA diseña una ruta a medida, dividida en lecciones paso a paso.

---

## Estado del Proyecto

En desarrollo activo (Beta / Funcional con detalles).
La aplicación es funcional y permite generar los cursos, pero actualmente se encuentra en una etapa donde pueden aparecer algunos errores menores y la experiencia de usuario para nuevos usuarios está siendo documentada y pulida. Las contribuciones y sugerencias son bienvenidas.

---

## Características Principales

* Generación Dinámica: Convierte cualquier prompt o consulta temática en un curso completo.
* Microaprendizaje Estructurado: Divide el contenido en lecciones lógicas y secuenciales, desde conceptos fundamentales hasta resolución práctica.
* Interfaz Personalizada: Desarrollada con PyQt6 bajo un diseño limpio y moderno.
* Validacion Robusta: Gestión de datos y esquemas mediante Pydantic.

## Instalación y Configuración

Desde la terminal debes ejecutar estos comandos en una carpeta libre de archivos.
1. Clonar el repositorio (o descarga el ZIP):
   ```bash
   git clone https://github.com/aagustinlu/MentorIA.git

2. Instalar las dependencias:
   ```bash
   pip install -r dependences.txt

## Uso

Una vez que hayas instalado correctamente y sin errores, debes ejecutar el archivo main.py para utilizar el programa.

Te pedirá que ingreses tu nombre y un API Key, para obtenerla dirígete a esta pagina: 
[Groq API Keys](https://console.groq.com/keys)
Regístrate y crea una. Una vez la tengas simplemente cópiala y ya podrás utilizar la aplicacion!

Para crear un curso debes presionar el boton, ubicado arriba a la derecha, e ingresar que curso deseas aprender (Puedes ingresar un archivo PDF con el botón +)
